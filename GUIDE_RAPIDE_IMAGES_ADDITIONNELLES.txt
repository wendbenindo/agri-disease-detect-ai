📋 ÉTAPE 1: EXÉCUTER LE SCRIPT SQL (OBLIGATOIRE)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Ouvrir Supabase (https://supabase.com)
2. Sélectionner votre projet
3. Cliquer sur "SQL Editor" dans le menu de gauche
4. Cliquer sur "New query"
5. Copier TOUT le contenu du fichier: supabase_product_images.sql
6. Coller dans l'éditeur
7. Cliquer sur "Run" (ou Ctrl+Enter)
8. Vérifier le message de succès

⏱️ Temps: 2 minutes

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🧪 ÉTAPE 2: TESTER L'AJOUT D'UN PRODUIT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Ouvrir l'application TipTiga
2. Aller dans "TipTiga Market"
3. Cliquer sur "Ajouter un produit"
4. Remplir les informations du produit
5. Dans "Photo du produit":
   - Cliquer sur "Sélectionner une image"
   - Choisir l'image principale
6. Dans "Images additionnelles":
   - Cliquer sur "Ajouter des images"
   - Sélectionner jusqu'à 5 images
   - Voir l'aperçu en grille
   - Cliquer sur ❌ pour supprimer une image si besoin
7. Cliquer sur "Enregistrer le produit"

⏱️ Temps: 5 minutes

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

👀 ÉTAPE 3: VÉRIFIER LE CARROUSEL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Retourner dans "TipTiga Market"
2. Cliquer sur le produit que vous venez de créer
3. Vérifier le carrousel d'images:
   ✓ Swiper gauche/droite pour naviguer
   ✓ Points blancs en bas (indicateurs)
   ✓ Compteur en haut à droite (ex: "2/5")
4. Cliquer sur une image pour la voir en plein écran
5. Pincer pour zoomer
6. Swiper pour naviguer entre les images

⏱️ Temps: 3 minutes

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROBLÈME: "Table 'product_images' does not exist"
SOLUTION: Exécuter le script supabase_product_images.sql

PROBLÈME: Les images ne s'affichent pas
SOLUTION: 
   1. Vérifier que le bucket 'product-images' existe
   2. Vérifier qu'il est configuré en public
   3. Vérifier les URLs des images

PROBLÈME: Erreur lors de l'upload
SOLUTION:
   1. Vérifier que vous êtes connecté
   2. Vérifier que vous êtes le propriétaire du produit
   3. Vérifier les politiques RLS
