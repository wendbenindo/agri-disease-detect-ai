Vérifiez les logs :

1. Si vous voyez "❌ ChatPage: userId est null"
   → Vous n'êtes pas connecté, connectez-vous d'abord

2. Si vous voyez "❌ Erreur markAsRead"
   → Problème avec la base de données
   → Vérifiez que la table messages existe
   → Vérifiez que la colonne is_read existe

3. Si vous voyez "✅ Messages marqués comme lus: 0 messages"
   → Aucun message à marquer (normal si vous êtes l'expéditeur)
   → Ou les messages sont déjà marqués comme lus

4. Si le badge ne disparaît pas après 500ms
   → Augmentez le délai à 1000ms (1 seconde)
   → Ou rechargez manuellement en tirant vers le bas
