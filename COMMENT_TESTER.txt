  COMMENT TESTER LE SYSTÈME DE VENDEURS - GUIDE ULTRA-SIMPLE

📱 LANCE L'APP
--------------
cd agri_desease_detect_app
flutter run


🧪 TEST 1 : BUYER DEMANDE À DEVENIR VENDEUR
--------------------------------------------
1. Ouvre l'app
2. Va dans "Profil" (onglet en bas)
3. Connecte-toi avec ton compte BUYER
4. Tu vois un bouton orange "Devenir vendeur" ? ✅
5. Clique dessus
6. Remplis :
   - Nom entreprise : "Test Agri"
   - Téléphone : +226XXXXXXXX
   - Ville : "Ouagadougou"
   - Région : "Centre"
7. Clique "Envoyer la demande"
8. Tu vois "Demande en attente" ? ✅


👨‍💼 TEST 2 : ADMIN APPROUVE LA DEMANDE
---------------------------------------
1. Déconnecte-toi
2. Connecte-toi avec ton compte ADMIN
3. Va dans "Profil"
4. Tu vois un bouton violet "Panel Administrateur" ? ✅
5. Clique dessus
6. Tu vois la demande du BUYER ? ✅
7. Clique "Approuver"
8. Confirme
9. Tu vois "Demande approuvée" ? ✅


🏪 TEST 3 : VENDOR PUBLIE UN PRODUIT
-------------------------------------
1. Déconnecte-toi
2. Reconnecte-toi avec le compte BUYER (maintenant VENDOR)
3. Va dans "Profil"
4. Tu vois un bouton vert "Ajouter un produit" ? ✅
5. Clique dessus
6. Remplis :
   - Nom : "Engrais NPK"
   - Prix : 25000
   - Catégorie : Choisis une
   - Description : "Test produit"
7. Clique "Publier"
8. Va dans "Marketplace"
9. Tu vois ton produit ? ✅


✅ SI TOUT MARCHE
-----------------
Félicitations ! Le système fonctionne parfaitement.
